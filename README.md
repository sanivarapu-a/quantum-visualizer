QuantumVisualizer is a web app that lets developers build, simulate, and understand quantum circuits without needing to write raw Qiskit code or deeply understand quantum computing syntax first.
It has a A drag-and-drop circuit composer, A built-in algorithm library, executes on Qiskit AER, Bloch sphere visualization. 
It also has version control for circuits as well so users can store the history of their circuit, revert to a certain version etc
